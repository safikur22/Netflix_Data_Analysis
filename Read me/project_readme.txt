================================================================================
NETFLIX MOVIES & TV SHOWS DATA ANALYSIS
================================================================================

PROJECT OVERVIEW
----------------
This project performs end-to-end data cleaning, preprocessing, and exploratory 
data preparation on the Netflix Movies & TV Shows dataset using Python, Pandas, 
and NumPy. The goal is to transform raw dataset records into a clean, 
standardized format ready for deeper analysis and visualization.

KEY OBJECTIVES & WORKFLOW
-------------------------
1. Data Loading & Inspection:
   - Imported the raw dataset (`netflix_data.csv`) using Pandas.
   - Inspected column data types, non-null counts, and overall dataset shape.

2. Missing Value & Duplicate Handling:
   - Checked for missing/null values across all columns.
   - Removed unnecessary columns (`description`, `show_id`).
   - Identified and removed duplicate records to maintain data integrity.
   - Imputed missing values in categorical columns (`director`, `cast`, 
     `country`) with `'Unknown'`.

3. Data Standardization & Transformation:
   - Renamed columns (`title` to `Movie_title`, `type` to `Movie_Type`) for 
     clarity.
   - Converted `date_added` to standard datetime format (`datetime64[ns]`) and 
     ensured `release_year` is stored as an integer (`int64`).
   - Stripped leading and trailing whitespaces from all text columns.

4. Verification & Export:
   - Verified the final dataset shape, duplicate count, remaining null values, 
     and data types.
   - Exported the cleaned dataset to `Netflix_cleaned_dataset.csv`.

FILES IN THIS PROJECT
---------------------
- netflix_data.csv             : Raw input dataset containing Netflix titles.
- netflix_data_analysis-v2.py  : Python script executing the cleaning pipeline.
- Netflix_cleaned_dataset.csv  : Output cleaned dataset generated by the script.
- README.txt                   : Project documentation.

PREREQUISITES & INSTALLATION
----------------------------
Make sure Python 3.x is installed along with the required libraries:

    pip install pandas numpy

HOW TO RUN
----------
1. Place `netflix_data.csv` in the same directory as the Python script.
2. Open a terminal/command prompt in the project directory.
3. Run the script:

    python netflix_data_analysis-v2.py

4. Upon completion, `Netflix_cleaned_dataset.csv` will be generated in the 
   same folder.
